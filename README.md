# Leonardo Maia — Psicólogo Clínico

Site institucional e portfólio profissional desenvolvido para o psicólogo clínico Leonardo Maia.

O site apresenta informações sobre o profissional, serviços oferecidos, abordagem de trabalho, perguntas frequentes e formas de contato para agendamento de consultas.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- React Icons

## Funcionalidades

- Página institucional responsiva
- Navegação por seções
- Modo claro e escuro
- Seção de serviços
- Seção sobre o profissional
- FAQ interativo
- Links para WhatsApp, Instagram, LinkedIn e E-mail
- Design responsivo para desktop e mobile
- SEO básico configurado

## Acesso

https://leonardopsicologo.vercel.app/

## Desenvolvimento

Projeto desenvolvido com React + TypeScript e Tailwind CSS, com foco em uma interface moderna, profissional e responsiva.
